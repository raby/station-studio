# API reference

The Station Studio REST API, auto-rendered from the running
FastAPI app's `app.openapi()` schema at docs-build time. The
JSON file consumed below (`openapi.json`) is regenerated by
`make docs-openapi` from `api.main:app`, then read by
[`mkdocs-render-swagger-plugin`][1] to embed Swagger UI inline.

[1]: https://github.com/bharel/mkdocs-render-swagger-plugin

Drift between the docs and the code is impossible by
construction — every push-to-main re-runs the dump, the diff
between runs only ever shows real API changes.

!!swagger openapi.json!!
